Security & Integrity

!

Hardcoded Teacher Credentials

The password for teacher resources is hardcoded in library/read/index.php. This is a high-risk vulnerability.

!

Potential Reflected XSS

The search query is echoed into the page title in pages/search.php. If the header template doesn't sanitize this, it may be exploitable.

Input Sanitization

Contact forms and user inputs generally use htmlspecialchars() and filters correctly.

Accessibility & UX

A11y Primitive Engine

The use of a central state controller and CSS variables for font, spacing, and theme overrides is an architectural masterpiece for neurodiversity.

Cognitive Toolset

The Reading Mask, Spotlight Mode, and Acoustic Ticks provide essential sensory control for students with ADHD and Dyslexia.

!

Keyboard Interaction

While basic support exists, some A11y tools could benefit from a more intuitive "snap-to-line" keyboard navigation.

Architecture & Quality

!

Lesson Content Redundancy

Lessons are stored as standalone PHP files. Updating the lesson layout requires editing 100+ files. Recommend moving to JSON + Template.

CSS Cascade Layers

Modern use of @layer ensures that accessibility overrides always take precedence over base styles.

!

Manual PWA Asset List

The service worker's asset list is manual. As the site grows, this will become a maintenance bottleneck.

Final Verdict

Hesten's Learning is a technically ambitious and ethically driven platform. While there are a few critical security gaps and maintenance hurdles, the core accessibility engine is industry-leading.
