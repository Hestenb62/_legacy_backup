## Interactive Digital Manipulatives Lab

Master abstract mathematics and science concepts visually! Located at `/pages/manipulatives.php`, the Interactive Manipulatives Lab provides three multi-sensory virtual laboratory studios designed for hands-on conceptual discovery.

### Available Laboratory Studios

- **1. Fraction Strips & Slices Studio:**
  - Build fraction bars and circular pizza slices from whole units down to 1/12ths.
  - Interactive comparisons: Add multiple fraction denominations to a shared comparison track.
  - Lowest Common Denominator (LCM) Auto-Solver: Visually decomposes different denominators into equivalent common denominator tiles.
  - Integrated MathJax: Formats real-time LaTeX algebraic equations illustrating addition and equivalence: $\frac{a}{b} + \frac{c}{d} = \frac{ad + bc}{bd}$.

- **2. Place Value Base-10 Blocks Studio:**
  - Build numbers using 3D visual blocks: Thousands Cubes ($1,000$), Hundreds Flats ($100$), Tens Rods ($10$), and Ones Units ($1$).
  - Compose & Decompose Animations: Select 10 ones units and click "Compose to 10-Rod", or select a Flat and click "Decompose to 10 Rods".
  - Expanded Notation Display: Real-time decomposition showing hundreds, tens, and ones with color-coded place values for dyscalculia support.

- **3. Dynamic Cartesian Function Grapher:**
  - Graph linear ($f(x) = mx + b$), quadratic ($f(x) = ax^2 + bx + c$), and sine wave ($f(x) = A\sin(Bx)$) functions.
  - Interactive parameter sliders: Adjust slope, intercept, curvature, and frequency in real time.
  - Vector SVG Plotter: Smooth 60fps graph updates with labeled axes, grid tick marks, and coordinate coordinates.
  - Live MathJax rendering: Automatically typesets the active algebraic formula above the graph.

### Universal Accessibility (UDL) & Accommodations
- **Keyboard Navigation:** 100% of add, remove, slider, and compose controls are operable via `Tab`, `Space`, `Enter`, and Arrow keys.
- **Screen Reader Announcements:** All quantity changes, block counts, and equivalent fraction calculations are announced via ARIA live regions.
- **Dyscalculia Color Coding:** High-contrast, standardized chromatic hues clearly delineate distinct place value magnitudes and fraction units.
- **100% Offline Capability:** Works completely without an active internet connection via Progressive Web App caching.
